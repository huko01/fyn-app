# fyn. app
A simple, clean web app for tracking your expenses, income, and net worth. Designed for mobile. Fyn.\
Try it now on the [GitHub page](https://huko01.github.io/fyn-app/).

**Information about updates**: If you use Fyn through the GitHub page, even if the source code in the GitHub repository is updated, the website will not update in your browser. To update it, first export your _.json_ data from settings (if you’ve created a password, you’ll need to remember it). Next, clear the website’s data from your browser settings. When you log back into Fyn and import your _.json_ data, the updates will have been applied.
