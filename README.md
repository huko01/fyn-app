# english
A simple, clean web app for tracking your expenses, income, and net worth. Designed for mobile. Fyn.\
Try it now on the [GitHub page](https://huko01.github.io/fyn-app/).

⚠️ If you access this website via the official link on the GitHub page, the source code may change as a result of various updates. To apply these updates correctly, export your data to a _.json_ file (settings), and then clear the website data in your browser settings. When you log back into Fyn, the code changes will have been applied, and you can click the button below to import your _.json_ file again. If you’ve previously created a password, you’ll need to enter it when importing your file.

🚧 Still in development.

# spanish 
Una aplicación web sencilla y clara para llevar un control de tus gastos, ingresos y patrimonio neto. Diseñada para dispositivos móviles. Fyn.
Pruébalo ahora en la [página de GitHub](https://huko01.github.io/fyn-app/).

⚠️ Si accedes a esta página web a través del enlace oficial de la página de GitHub, el código fuente puede sufrir cambios como consecuencia de diversas actualizaciones. Para aplicar estas actualizaciones correctamente, exporta tus datos a un archivo _.json_ (ajustes) y, a continuación, borra los datos del sitio web en la configuración de tu navegador. Cuando vuelvas a iniciar sesión en Fyn, los cambios en el código se habrán aplicado y podrás hacer clic en el botón de abajo para importar de nuevo tu archivo _.json_. Si has creado una contraseña anteriormente, tendrás que introducirla al importar el archivo.

🚧 Todavía en desarrollo.
